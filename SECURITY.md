# Security Policy

## Supported Versions

Security fixes are applied to the current `main` branch.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository when available. Otherwise, contact the maintainers through the repository owner profile with:

- A concise description and affected component.
- Reproduction steps or a proof of concept.
- Potential impact and any suggested mitigation.

Reports receive an acknowledgement within five business days. Please allow maintainers reasonable time to investigate and release a fix before disclosure.
