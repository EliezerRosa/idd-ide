IDD — Intent-Driven Development

na formulação de Eliézer Rosa

O IDD é uma disciplina de engenharia de software com IA. A intenção humana, escrita em linguagem natural, é a fonte de autoridade do sistema. Ela é compilada em contratos estruturados, que uma verificação determinística confere continuamente.

  • Repositório (código, Cânone e acervo): github.com/EliezerRosa/idd-ide
  • Canal no YouTube: youtube.com/@eliezerjprosa

Sobre a automação do canal

O projeto inclui scripts que usam a YouTube Data API para publicar vídeos e manter títulos, descrições e playlists do canal do próprio autor. A automação acessa somente as contas do autor e não é oferecida a terceiros.
