⚙️ Admin UI — Gestão de Permissões em Tempo Real

Dois painéis: políticas gerais e exceções individuais.

📜 Painel de Políticas

permission_policies
✏️
Criar nova políticaDefinir funcao + privilegio, escolher allowed_actions (multi-select), data_access_level, toggle sensível, prioridade
📝
Editar existenteAlterar qualquer campo, reordenar prioridade
🗑️
Excluir políticaCom diálogo de confirmação
🔄
Efeito imediatoCache invalidado automaticamente, sem restart

👤 Painel de Overrides

user_permission_overrides
🎯
Dar mais permissõesSM "Carlos" precisa ver dados sensíveis → Override: can_access_sensitive = true
🔒
Restringir permissõesAncião "Manuel" não pode usar agente → Override: allowed_actions = []
⚡
Prioridade superiorOverride sempre vence a política base, pode ter data de expiração
📊
AuditoriaHistórico: quem criou, quando, porquê (created_by)
🔀 Ordem: Override do User → Política (funcao + privilegio) → Política (funcao) → Default (sem acesso)
💡 Tudo gerido pelo Ancião na aba Admin, sem necessidade de código ou deploy!
